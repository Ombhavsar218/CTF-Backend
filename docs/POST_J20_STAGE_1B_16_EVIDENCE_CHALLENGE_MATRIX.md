## 1. Method and grading definitions

For each material security claim below:

- **Implementation location** was read directly from current source (not inferred from reports).
- **Test/result** is attributed to test source and/or a preserved raw artifact. No test was executed in this milestone; "passed" always means "recorded in a raw artifact", never "independently executed by this review".
- **Independently inspected** = `YES` when this review read the actual implementation and the raw artifact; `PARTIAL` when source or artifact was read but the counterpart is missing/unavailable; `NO` only for claims resting purely on a historical report.
- **Assessment** uses: `Fully verified (scoped)`, `Partially verified`, `Unresolved`, `Unverified`.

All conclusions are explicitly scoped to the **mock-only** boundary unless stated otherwise.
